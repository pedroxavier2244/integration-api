# Documentacao

## Guias principais

- [Guia de Manutencao da Integration API](manutencao-api.md)
- [Guia de Integracao da Integration API](guia-integracao.md)

## Publico alvo

- times de backend, devops e sustentacao: use o guia de manutencao
- times de frontend, CRM, BI leve e integradores: use o guia de integracao

## Quando usar cada documento

Use o guia de manutencao quando voce precisar:

- publicar ou rebuildar a API
- diagnosticar erros de infraestrutura
- entender ownership de banco e tabelas
- operar usuarios, auditoria e ambiente

Use o guia de integracao quando voce precisar:

- autenticar
- consumir endpoints
- implementar frontend
- integrar CRM ou servicos externos

## Ordem recomendada de leitura

1. comece pelo [Guia de Integracao da Integration API](guia-integracao.md) se o objetivo for consumir a API
2. use o [Guia de Manutencao da Integration API](manutencao-api.md) para operacao, deploy e sustentacao
